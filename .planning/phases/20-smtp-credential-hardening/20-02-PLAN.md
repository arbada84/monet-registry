# Phase 20-02 Plan: Admin UX, runbook, and closure

## Goal

Make SMTP credential management understandable and safe for operators, then close v4.0 with tests, documentation, and production-safe validation.

## Tasks

1. Harden admin UX.
   - Show when SMTP credentials are environment-managed.
   - Prevent masked placeholders from overwriting environment-managed secrets.
   - Keep non-secret sender/reply-to metadata editable where safe.

2. Add operator documentation.
   - Document required Vercel environment variables.
   - Explain DB fallback behavior and migration steps.
   - Include smoke checks for SMTP test and newsletter send.

3. Close validation.
   - Add or update tests for admin settings masking/status behavior.
   - Run planning guard, lint, typecheck, unit tests, audit, and build.
   - Record v4.0 closure status.

## Non-Goals

- Do not perform a live SMTP send without explicit operator intent.
- Do not rotate production credentials automatically.
- Do not include broader Cloudflare runtime cutover work.

## Acceptance Criteria

- Admin screens make env-managed SMTP state clear without exposing secrets.
- Runbook covers Vercel env setup and fallback removal.
- Full validation passes on the Linux working tree.
