# Phase 18-02 Plan: Telegram command/report verification

## Goal

Close `OPS-01` by making Telegram commands and daily reports surface auto-press run state, retry queue state, DLQ/source quality summaries, and actionable Korean operator messages.

## Context

Phase 18-01 verified that AI retry processing is D1 queue driven. Telegram already exposes retry queue, queued auto-press items, and source quality commands, but DLQ coverage and daily report summaries need to be explicit so operators can see what to inspect without opening the admin dashboard first.

## Tasks

1. Audit Telegram command coverage.
   - `/status`
   - `/retry_queue`
   - `/auto_press_queue`
   - `/auto_press_sources`
   - `/report`

2. Add missing DLQ command coverage.
   - Add `/auto_press_dlq` with aliases.
   - Include DLQ totals, reason buckets, oldest/latest timestamps, sample failed items, and retry/discard guidance.

3. Strengthen daily reports.
   - Site report: include observed run state, retry queue, DLQ, source quality, and next actions.
   - Worker report: include D1 retry queue and DLQ counts in the Worker-owned daily Telegram report.

4. Add tests/static guards.
   - Unit-test Telegram commands for DLQ and Korean action text.
   - Unit-test the site daily report summary.
   - Extend Worker static tests and the auto-press agent-loop guard for Telegram operations.

5. Run verification.
   - `pnpm test:unit tests/unit/telegram-commands.test.ts tests/unit/telegram-notify.test.ts tests/unit/telegram-report.test.ts tests/unit/auto-press-worker-runtime-controls.test.ts`
   - `pnpm check:auto-press-agent-loop`
   - `pnpm check:planning`
   - `pnpm ci:typecheck`

## Non-Goals

- Do not send live Telegram messages.
- Do not mutate live D1, Worker, or Telegram settings.
- Do not change retry processing behavior from Phase 18-01.

## Acceptance Criteria

- Telegram commands expose run, retry queue, DLQ, and source quality state with Korean action guidance.
- Site and Worker daily reports include retry queue and DLQ/source quality summaries.
- OPS-01 is marked complete after focused tests and static guards pass.
