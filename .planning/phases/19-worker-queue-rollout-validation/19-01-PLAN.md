# Phase 19-01 Plan: Worker/Queue dispatch and DLQ rollout verification

## Goal

Close `AUTO-09` by verifying that the Cloudflare Worker/Queue path preserves duplicate guards, source scope controls, worker notification auth, DLQ recovery actions, and cache revalidation.

## Context

Phases 15-18 made auto-press observable, retryable, and visible in Telegram. Phase 19 validates the Worker/Queue path as the rollout surface without changing the live runtime cutover. Existing implementation already has D1 queue rows, Worker dispatch helpers, source eligibility checks, DLQ actions, and worker result notification; this phase makes those contracts explicit in tests and static guards.

## Tasks

1. Verify Worker dispatch contracts.
   - Dispatch uses `AUTO_PRESS_WORKER_ENQUEUE_URL`.
   - Process requests use `AUTO_PRESS_WORKER_PROCESS_URL` or `/enqueue` -> `/process` fallback.
   - Both requests require `AUTO_PRESS_WORKER_SECRET` and `Authorization: Bearer ...`.
   - Disabled dispatch exits before network calls.

2. Verify source scope and duplicate guards.
   - Source eligibility runs before AI edit.
   - Out-of-scope sources become skipped observed items.
   - Queue messages preserve `sourceId`.
   - Same-title duplicate checks remain active even when source URLs differ.

3. Verify Worker notification and DLQ recovery.
   - `/api/auto-press/worker-notify` rejects unauthenticated requests.
   - Worker-published items revalidate the `articles` tag.
   - DLQ retry requeues the item and dispatches Worker processing.
   - DLQ discard does not dispatch Worker processing.

4. Add tests/static guards.
   - Add focused dispatch helper unit coverage.
   - Extend Worker/source-scope and observability route tests.
   - Extend `pnpm check:auto-press-agent-loop` with the rollout contract.

5. Run verification.
   - `pnpm test:unit tests/unit/auto-press-worker-dispatch.test.ts tests/unit/auto-press-worker-scope-guard.test.ts tests/unit/auto-press-observability-routes.test.ts tests/unit/auto-press-worker-runtime-controls.test.ts`
   - `pnpm check:auto-press-agent-loop`
   - `pnpm check:planning`
   - `pnpm ci:typecheck`

## Non-Goals

- Do not deploy Worker or mutate live Cloudflare queues.
- Do not switch the whole site to Cloudflare-first runtime.
- Do not change auto-press source policy beyond validating the existing guards.

## Acceptance Criteria

- Worker dispatch and process helpers are covered for auth, config, disabled mode, and payload shape.
- Worker source scope guard is verified before AI work.
- Worker notification auth/cache revalidation and DLQ retry/discard routes are covered.
- `AUTO-09` can be marked complete after focused tests and static guards pass.
